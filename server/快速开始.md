# EverMemOS Memory Server - 快速开始指南

## 项目概述

这是一个基于 FastAPI 的服务器，集成了 EverMemOS 记忆存储服务，提供两个核心接口：
1. **存储记忆**：为指定用户存储一段记忆
2. **批量查询**：批量查询多个 (用户 ID, 查询问题) 的记忆

```
server/

```

## 快速开始

### 1. 安装依赖

```bash
cd server
pip install -r requirements.txt
```

### 2. 配置环境变量

复制配置文件并设置你的 API 密钥：

```bash
cp .env.example .env
```

编辑 `.env` 文件：
```bash
EVERMEMOS_API_KEY=your_actual_api_key
DEFAULT_GROUP_ID=default_group
```

### 3. 启动服务器

**Linux/Mac:**
```bash
chmod +x start.sh
./start.sh
```

**Windows:**
```bash
start.bat
```

**或直接运行：**
```bash
python main.py
```

服务器将在 `http://localhost:8000` 启动

## API 接口说明

### 接口 1: 存储记忆

**端点**: `POST /memories/store`

**功能**: 为指定用户存储一段记忆

**请求参数**:
```json
{
  "user_id": "user_demo_001",              // 用户 ID
  "memory": {
    "message_id": "msg_001",               // 消息唯一标识
    "create_time": "2025-01-15T10:00:00Z", // ISO 8601 时间戳
    "sender": "user_demo_001",             // 发送者 ID
    "sender_name": "Demo User",            // 发送者名称
    "content": "我喜欢黑咖啡，不加糖！",   // 记忆内容
    "group_id": "group_001"                // 可选的组 ID
  }
}
```

**响应示例**:
```json
{
  "status": "success",
  "message": "Memory stored successfully",
  "request_id": "req_123456"
}
```

### 接口 2: 批量查询记忆

**端点**: `POST /memories/batch-query`

**功能**: 批量查询多个用户的记忆

**请求参数**:
```json
{
  "queries": [
    {
      "user_id": "user_demo_001",    // 用户 ID
      "query": "咖啡偏好"            // 查询问题
    },
    {
      "user_id": "user_demo_002",
      "query": "食物偏好"
    }
  ]
}
```

**响应示例**:
```json
{
  "results": [
    {
      "user_id": "user_demo_001",
      "query": "咖啡偏好",
      "total_count": 3,        // 匹配的记忆数量
      "success": true,
      "error": null
    },
    {
      "user_id": "user_demo_002",
      "query": "食物偏好",
      "total_count": 5,
      "success": true,
      "error": null
    }
  ]
}
```

### 接口 3: 健康检查

**端点**: `GET /health`

**功能**: 检查服务器是否正常运行

**响应示例**:
```json
{
  "status": "healthy",
  "timestamp": "2025-01-15T10:30:00Z"
}
```

## 使用示例

### 使用 curl 命令

**存储记忆**:
```bash
curl -X POST "http://localhost:8000/memories/store" \
  -H "Content-Type: application/json" \
  -d '{
    "user_id": "user_001",
    "memory": {
      "message_id": "msg_001",
      "create_time": "2025-01-15T10:00:00Z",
      "sender": "user_001",
      "sender_name": "张三",
      "content": "我喜欢黑咖啡，不加糖！",
      "group_id": "group_001"
    }
  }'
```

**批量查询**:
```bash
curl -X POST "http://localhost:8000/memories/batch-query" \
  -H "Content-Type: application/json" \
  -d '{
    "queries": [
      {"user_id": "user_001", "query": "咖啡偏好"},
      {"user_id": "user_002", "query": "食物偏好"}
    ]
  }'
```

### 使用 Python

```python
import requests

# 存储记忆
response = requests.post(
    "http://localhost:8000/memories/store",
    json={
        "user_id": "user_001",
        "memory": {
            "message_id": "msg_001",
            "create_time": "2025-01-15T10:00:00Z",
            "sender": "user_001",
            "sender_name": "张三",
            "content": "我喜欢黑咖啡！",
            "group_id": "group_001"
        }
    }
)
print(response.json())

# 批量查询
response = requests.post(
    "http://localhost:8000/memories/batch-query",
    json={
        "queries": [
            {"user_id": "user_001", "query": "咖啡偏好"}
        ]
    }
)
print(response.json())
```

## 错误处理

服务器提供完善的错误处理：

- **422 Error**: 请求数据格式错误（验证失败）
- **500 Error**: EverMemOS API 调用失败
- **连接错误**: 服务器未启动或网络问题

每个查询在批量操作中独立处理，单个查询失败不影响其他查询。

## 注意事项

1. **时间格式**: 必须使用 ISO 8601 格式（如：`2025-01-15T10:00:00Z`）
2. **sender 字段**: 自动设置为请求中的 `user_id`
3. **group_id**: 可选，不提供则使用环境变量中的默认值
4. **API Key**: 必须配置正确的 EverMemOS API 密钥
5. **批量查询**: 支持同时查询多个用户的多个问题
